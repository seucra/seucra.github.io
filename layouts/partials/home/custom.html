PRACTICAL WORK

Projects I’m building to learn.

01 / ONGOING PROJECT

Vigilant

An ongoing project exploring secure communication using the Matrix ecosystem, Rust, WebAssembly, and a self-hosted Synapse server rather than reinventing cryptography.

Project overview → 02 / EXTRACTED LIBRARY

Matrix SDK Bridge

A small Rust-to-WebAssembly bridge published on npm (@seucra/matrix-sdk-bridge), extracted from Vigilant so browser JavaScript can interact with the client cleanly.

Library notes → 03 / SYSTEMS EXPERIMENT

Triton

A multi-crate Rust CLI utility experimenting with multi-threaded directory walks (Rayon), project root detection, and caching build artifacts with SQLite and BLAKE3.

System notes → 04 / COLLEGE STUDY

Vulnerability Prioritization

A collaborative academic project with college peers exploring how NVD disclosures, EPSS likelihoods, and DuckDB analytics can support practical vulnerability triage.

Read paper summary → 05 / HACKATHON (PS SIH26184)

CyberShield

Our team’s submission for Smart India Hackathon (Problem Statement SIH26184), designing a pipeline to forecast cash-out points and apply partial account holds in cyber fraud cases.

Hackathon breakdown → 06 / RETROSPECTIVE

CipherLink

An earlier personal attempt to write a secure messenger from scratch. It taught me how difficult protocol design is and convinced me to adopt Matrix instead.
