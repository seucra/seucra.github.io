Successfully extracted the Matrix integration layer from [Vigilant](/projects/vigilant/) into an independent Rust library, compiled it to WebAssembly and published it as an npm package: [`@seucra/matrix-sdk-bridge`](https://www.npmjs.com/package/@seucra/matrix-sdk-bridge) ([GitHub Repository](https://github.com/seucra/matrix-sdk-bridge)).

This milestone represented more than a successful release—it marked the transition from application-specific code to reusable infrastructure.
