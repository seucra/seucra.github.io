# Primary Project

## Vigilant

Vigilant is the largest backend project I have worked on.

The backend is responsible for:

- User authentication
- Session persistence
- Room management
- Messaging
- Timeline synchronization
- Direct messaging
- Notifications
- Matrix SDK integration

The project is written primarily in Rust and exposes functionality to the frontend through a WebAssembly bridge.
