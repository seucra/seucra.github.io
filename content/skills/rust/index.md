# Overview

Rust is the language around which my current engineering journey is centered.

I began learning Rust after realizing I wanted to move beyond academic programming and understand how production-quality backend and systems software is designed. Since then, it has become the primary language used throughout my long-term projects.

Rather than learning Rust through isolated exercises, I use it to solve real engineering problems involving networking, asynchronous programming, APIs and systems integration.

---

# Why Rust?

Rust aligned closely with the type of software I wanted to build.

It combines performance with strong compile-time guarantees, making it well suited for backend systems, infrastructure and applications where correctness matters.

Learning Rust also encouraged me to think differently about ownership, concurrency and software architecture instead of relying on habits formed in garbage-collected languages.

Learning Rust fundamentally changed how I approach programming.

Compiler feedback has become part of the design process rather than something to work around.
