Learning Rust marked the largest shift in how I approached programming.

Rather than focusing primarily on completing features, I began paying closer attention to ownership, memory safety, architecture, asynchronous programming and long-term maintainability.

This change influenced nearly every later technical decision, eventually leading to projects centered around backend engineering, distributed systems and secure communication.

Rust also became the language through which I began contributing to open source and exploring systems programming in greater depth.
