Vigilant became my flagship engineering project after rethinking the direction of an earlier secure messaging concept.

Instead of attempting to build an entirely new messaging protocol, the project adopted the Matrix ecosystem and focused on building reliable backend systems using Rust and WebAssembly.

Working on Vigilant expanded my understanding of backend architecture, infrastructure, distributed systems and long-term software design far beyond what smaller academic projects had provided.
