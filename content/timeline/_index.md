## 2025 — The Rust Shift & Protocol Adoption

* **Early 2025**: **Adopting Rust & Systems Programming**  
  Shifted from imperative feature assembly to memory-safe systems programming in Rust. Focused on ownership, lifetime boundaries, type safety, and concurrency.
* **Mid 2025**: **Matrix Protocol Pivot**  
  Rethought custom protocol development (CipherLink) and chose to adopt the open federated Matrix protocol, prioritizing application architecture and backend integration over protocol reinvention.
* **Late 2025**: **Open Source & Algorithm Implementations**  
  Implemented algorithms and data structures in Rust and contributed to Rosetta Code.
