# About

I'm Shams Tabrez Ahmed, a Computer Science student focused on backend engineering, systems programming and cybersecurity.

Over the last few years my interests have shifted away from simply completing academic projects toward understanding how real software systems are designed, built and maintained. Rather than collecting technologies, I prefer using projects as vehicles to develop engineering depth.

My current work is centered around Rust, distributed systems, Linux, backend architecture and secure communication.

## Current Projects

### Vigilant

Vigilant is my flagship engineering project. It explores secure communication using the Matrix ecosystem, Rust and WebAssembly. Instead of attempting to reinvent secure messaging protocols, the project builds upon Matrix while focusing on reliable backend engineering and infrastructure.

### Vulnerability Prioritization

An applied cybersecurity research project investigating how public vulnerability intelligence from sources such as NVD, EPSS and CISA KEV can be combined into a practical prioritization workflow.

## Engineering Philosophy

I prefer learning through long-term projects that expose real engineering problems.

Understanding why a system is designed a certain way is more valuable than quickly assembling something that only appears to work.

Whenever possible I build on established technologies instead of reimplementing mature infrastructure. This allows me to spend more time understanding architecture, integration and trade-offs.
