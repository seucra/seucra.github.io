# Systems & Projects

This catalog documents the primary software systems engineered across backend architecture, Rust, WebAssembly, distributed protocols, and cybersecurity.

Every project represents an intentional problem space: making boundaries explicit, exploring trade-offs, and testing architectures in practice.

---

### Project Classifications

* **Flagship Systems**: End-to-end architectures demonstrating multi-layered engineering ([Vigilant](/projects/vigilant/), [CyberShield](/projects/sih2026/)).
* **Published Libraries**: Extracted, reusable packages published to package registries ([@seucra/matrix-sdk-bridge](/projects/matrix-sdk-bridge/)).
* **Systems Engines**: Performance-critical filesystem and data engines written in Rust ([Triton](/projects/triton/)).
* **Historical Precursors**: Foundational projects whose design lessons informed later systems ([CipherLink](/projects/cipherlink/)).
