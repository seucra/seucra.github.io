## Overview

Vigilant is a Matrix-powered secure communication platform focused on providing modern messaging infrastructure while leveraging the Matrix ecosystem instead of reinventing a protocol.

---

## Motivation

Initially started as a secure messaging application, the project evolved after discovering Matrix and Synapse. Instead of implementing another messaging protocol, the project shifted toward building on proven infrastructure.
